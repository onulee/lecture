🧑‍🏫 2. 강의 스크립트 (말하기용)
🎬 [슬라이드 1] 오프닝

“안녕하세요. 오늘은 Claude Code를 활용해서
PPT 생성 스킬을 직접 만들고, 마켓플레이스에 배포하는 방법까지
한 번에 정리해보겠습니다.”

🎬 [슬라이드 2] Claude Code란?

“Claude Code는 AI가 코드를 이해하고 실행하면서
자동으로 결과를 만들어주는 개발 환경입니다.

여기서 핵심은 ‘Skill’입니다.
Skill은 특정 작업을 자동으로 수행하는 작은 AI 프로그램입니다.”

🎬 [슬라이드 3] 오늘 만들 것

“오늘 우리가 만들 것은
텍스트만 입력하면 자동으로 PPT를 만들어주는 Skill입니다.

예를 들어
‘SaaS 설명 PPT 만들어줘’라고 하면
슬라이드 구조까지 자동 생성되게 할 겁니다.”

🎬 [슬라이드 4] Skill 구조 이해

“Skill은 크게 3가지로 구성됩니다.

역할 정의 (무엇을 하는지)
입력 구조 (사용자가 무엇을 넣는지)
출력 형태 (어떤 결과를 만드는지)

이 구조만 이해하면 어떤 Skill이든 만들 수 있습니다.”

🎬 [슬라이드 5] PPT Skill 설계

“PPT Skill은 이렇게 설계합니다.

입력: 주제
출력: 슬라이드 리스트
형식: 제목 + 내용

중요한 포인트는
AI가 슬라이드 구조를 먼저 생각하게 만드는 것입니다.”

🎬 [슬라이드 6] Skill Creator 작성

“이제 실제로 Skill을 만들어보겠습니다.

핵심은 프롬프트입니다.

AI에게 이렇게 지시합니다:

‘너는 PPT 전문가다.
사용자가 주제를 주면
슬라이드 구조를 만들어라.’

이렇게 역할을 명확하게 주는 것이 중요합니다.”

🎬 [슬라이드 7] 출력 포맷 정의

“출력은 반드시 구조화해야 합니다.

예를 들어:

Slide 1: 제목
Slide 2: 개요
Slide 3: 핵심 내용

이렇게 하면
나중에 HTML이나 PPT로 변환하기 쉬워집니다.”

🎬 [슬라이드 8] 실행 테스트

“이제 Claude Code에서 실행해봅니다.

예시 입력:
‘스타트업 투자 PPT 만들어줘’

결과:
자동으로 10장 이상의 슬라이드 생성

여기서 중요한 건
결과를 계속 수정하면서 품질을 높이는 것입니다.”

🎬 [슬라이드 9] HTML PPT 변환

“생성된 슬라이드는
HTML, CSS, JavaScript로 변환할 수 있습니다.

이렇게 하면
웹 기반 PPT로 바로 사용 가능합니다.”

🎬 [슬라이드 10] Marketplace 배포

“이제 만든 Skill을 배포합니다.

과정은 간단합니다.

Skill 등록
설명 작성
사용 방법 정의
공개 설정

이렇게 하면 다른 사람도 사용할 수 있습니다.”

🎬 [슬라이드 11] 배포 시 핵심 포인트

“배포할 때 중요한 건 3가지입니다.

명확한 설명
좋은 예시 입력
결과 품질

이 3개가 좋으면 사용자가 많아집니다.”

🎬 [슬라이드 12] 활용 방법

“이 Skill은 이렇게 활용할 수 있습니다.

강의 자료 제작
회사 발표 자료
마케팅 기획 PPT

즉, 반복 작업을 자동화하는 도구입니다.”

🎬 [슬라이드 13] 확장 아이디어

“여기서 더 발전시키면

디자인 자동 적용
이미지 자동 삽입
차트 생성

까지 확장할 수 있습니다.”

🎬 [슬라이드 14] 마무리

“오늘은 Claude Code를 활용해서
PPT 생성 Skill을 만들고
마켓플레이스에 배포하는 과정까지 살펴봤습니다.

핵심은
‘구조를 잘 설계하는 것’입니다.”
