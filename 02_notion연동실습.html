📝 Notion 연동 실습

업무 미팅 항목 작성

Claude + Notion 연동으로 업무 미팅 데이터베이스를 자동으로 구성하고,
회의 관련 항목을 Claude가 직접 채워주는 방법을 실습합니다.

데이터베이스 설계

🗂 업무 미팅 데이터베이스 구조

실무에서 필요한 미팅 관련 항목을 아래와 같이 설계합니다.

항목명타입설명
회의명Title미팅의 이름 (예: 3월 마케팅 전략 회의)
날짜Date회의 일시
참석자People참석하는 팀원
안건Text논의할 주요 안건 목록
회의록Text회의 중 작성된 내용 요약
결정 사항Text회의에서 결정된 내용
Action ItemText후속 조치 및 할 일 목록
담당자PeopleAction Item 별 담당자
마감일DateAction Item 마감 기한
상태Select예정 / 진행 중 / 완료
실습 1

🧪 미팅 항목 데이터베이스 생성

프롬프트Notion에 "업무 미팅 관리" 데이터베이스를 만들어줘. 아래 항목을 포함해서 만들어줘: - 회의명 (제목) - 날짜 (날짜/시간) - 참석자 (사람) - 안건 (텍스트) - 회의록 (텍스트) - 결정 사항 (텍스트) - Action Item (텍스트) - 담당자 (사람) - 마감일 (날짜) - 상태 (선택: 예정/진행 중/완료)
✏️ 직접 해보기: 위 프롬프트를 Claude에 붙여넣고 실행해보세요.
실습 2

🧪 새 미팅 항목 자동 입력

프롬프트Notion 업무 미팅 관리 데이터베이스에 새 항목을 추가해줘. 회의 정보: - 회의명: Q2 마케팅 전략 회의 - 날짜: [날짜 입력] - 참석자: 기획팀 전원 - 안건: 1. Q2 캠페인 예산 검토 2. SNS 채널 운영 방향 3. 협력사 미팅 일정 조율 - 상태: 예정
💡 날짜와 참석자를 실제 정보로 바꿔서 실행해보세요.
실습 3

🧪 회의록 자동 정리 후 Notion 저장

프롬프트아래는 방금 끝난 미팅 메모야. 이것을 정리해서 Notion 업무 미팅 관리 데이터베이스에 저장해줘. [내 회의 메모 붙여넣기] 아래 항목으로 분리해서 저장해: - 회의록 (주요 논의 내용 요약) - 결정 사항 (확정된 내용만) - Action Item (담당자/할 일/마감일 표 형식) - 상태: 완료
📋 메모나 녹취 텍스트를 붙여넣으면 Claude가 자동으로 구조화합니다.
실습 4

🧪 미팅 현황 조회

Notion에서 이번 주 예정된 미팅 목록을 보여줘
Notion에서 완료되지 않은 Action Item이 있는 미팅을 찾아줘
[담당자 이름]에게 배정된 Action Item 목록을 Notion에서 조회해줘
🔍 조회 프롬프트를 활용하면 Notion DB를 자연어로 검색할 수 있습니다.
Claude 활용 가이드

📋 항목별 Claude 활용 팁

📌 안건
미팅 목적을 말하면 안건 초안을 자동으로 작성해줍니다.
📝 회의록
녹취나 메모를 붙여넣으면 핵심 내용을 자동으로 요약합니다.
✅ Action Item
회의록에서 할 일을 자동 추출하고 담당자까지 배정합니다.
📧 후속 이메일
회의록 기반으로 참석자 공유용 이메일을 자동 생성합니다.
실습 완료 확인

  • 새 미팅 항목을 Claude로 추가했다
  • 회의 메모를 회의록으로 변환해 저장했다
  • 미팅 현황 조회 프롬프트를 실행해봤다
