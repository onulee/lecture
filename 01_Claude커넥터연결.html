커넥터(Connectors)란?

🔌 커넥터는 Claude가 외부 서비스와 직접 연동되어 실제 데이터를 읽고 쓸 수 있게 해주는 기능입니다.
Notion 페이지 생성, 캘린더 일정 등록, Figma 디자인 제어까지 — 모두 대화 한 번으로 가능해져요.

Step 1

커넥터 메뉴 접근 방법

단계내용
1claude.ai 에 접속해 로그인합니다
2채팅창 왼쪽 하단 또는 설정(⚙️) 메뉴를 클릭합니다
3"Connections" 또는 "커넥터" 탭을 선택합니다
🟣 Notion 커넥터 연결

연결 단계

1Connections 탭에서 Notion 선택
2"Connect" 버튼 클릭
3Notion 로그인 팝업에서 계정 인증
4연동할 워크스페이스 선택 후 허용
5Claude 화면으로 돌아와 ✅ 연결 확인

연결 후 할 수 있는 것

  • 새 페이지 / 데이터베이스 생성
  • 기존 페이지 검색 및 내용 추가
  • 데이터베이스에 항목(레코드) 추가
  • 페이지 요약 및 내용 분석

실습 프롬프트

"Notion에서 오늘 날짜로
 새 회의록 페이지를 만들어줘"
"내 Notion 워크스페이스에서
 마케팅 관련 페이지를 찾아줘"
🔵 Google Calendar 커넥터 연결

연결 단계

1Connections 탭에서 Google Calendar 선택
2"Connect" 버튼 클릭
3Google 계정 선택 및 로그인
4캘린더 읽기/쓰기 권한 허용
5Claude 화면으로 돌아와 ✅ 연결 확인

연결 후 할 수 있는 것

  • 일정 생성 / 수정 / 삭제
  • 특정 기간 일정 조회
  • 반복 일정(매주, 매월) 설정
  • 참석자 초대 포함 일정 등록

실습 프롬프트

"다음 주 월요일 오전 10시에
 팀 회의 일정을 추가해줘"
"이번 달 내 일정을 요약해줘"
🟢 Figma 커넥터 연결

연결 단계

1Connections 탭에서 Figma 선택
2"Connect" 버튼 클릭
3Figma 계정 로그인
4접근 권한 허용
5Claude 화면으로 돌아와 ✅ 연결 확인

연결 후 할 수 있는 것

  • Figma 파일 내용 읽기 및 분석
  • 디자인 컴포넌트 정보 조회
  • 프레임/레이어 구조 파악
  • 코드 커넥트 및 에셋 연동

실습 프롬프트

 컴포넌트 스타일을 분석해줘"
