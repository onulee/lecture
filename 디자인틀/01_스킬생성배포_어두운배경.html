Slide 02 · 개념

Claude Code란?

AI가 코드를 이해하고 실행하면서
자동으로 결과를 만들어주는 개발 환경

Skill 중심 구조 자동화 실행 AI 기반 코드 이해

여기서 핵심은 'Skill'입니다.
Skill은 특정 작업을 자동으로 수행하는 작은 AI 프로그램입니다.

Slide 03 · 목표

오늘 만들 것

텍스트만 입력하면
자동으로 PPT를 만드는 Skill

# 사용자 입력
> "SaaS 설명 PPT 만들어줘"

# 자동 생성 결과
✓ 슬라이드 구조 자동 생성
✓ HTML / CSS / JS 완성본 출력
Slide 04 · 구조

Skill 구조 이해

01
역할 정의
무엇을 하는 Skill인지 명확하게 정의
02
입력 구조
사용자가 무엇을 입력하는지 규정
03
출력 형태
어떤 결과를 어떤 형식으로 만드는지

이 구조만 이해하면 어떤 Skill이든 만들 수 있습니다.

Slide 05 · 설계

PPT Skill 설계

Input
  • 주제 (텍스트)
  • 슬라이드 수 (선택)
  • 톤 / 스타일 (선택)
Output
  • 슬라이드 리스트
  • 각 슬라이드: 제목 + 내용
  • HTML 완성 파일

핵심 포인트: AI가 슬라이드 구조를 먼저 생각하게 만드는 것

Slide 06 · 제작

Skill Creator 작성

핵심은 프롬프트 설계입니다. AI에게 역할을 명확하게 줘야 합니다.

# SKILL.md 핵심 구조
역할: 너는 PPT 전문가다
입력: 사용자가 주제를 제공
동작: 슬라이드 구조를 먼저 설계
출력: 완성된 HTML 파일 생성

역할을 명확하게 줄수록 결과 품질이 높아집니다.

Slide 07 · 포맷

출력 포맷 정의

출력은 반드시 구조화해야 합니다.

Slide 1: 제목 슬라이드
Slide 2: 개요 / 목차
Slide 3: 핵심 내용 #1
Slide 4: 핵심 내용 #2
... (구조화된 슬라이드 리스트)

구조화된 출력은 HTML / PPT 변환을 쉽게 만들어 줍니다.

Slide 08 · 테스트

실행 테스트

예시 입력

"스타트업 투자
PPT 만들어줘"

결과
  • 10장 이상 슬라이드 자동 생성
  • 각 슬라이드 내용 완성
  • HTML 파일 즉시 사용 가능

중요: 결과를 계속 수정하면서 품질을 높이는 반복 과정이 핵심입니다.

Slide 09 · 변환

HTML PPT 변환

단일 HTML 파일 →
웹 기반 프레젠테이션

HTML CSS JavaScript
  • 서버 없이 브라우저에서 즉시 실행
  • 키보드 / 터치 네비게이션 포함
  • 외부 라이브러리 의존 없음
  • F키로 풀스크린 전환
Slide 10 · 배포

Marketplace 배포

Skill 등록 → 설명 작성 → 사용법 정의 → 공개 설정

배포 후에는 다른 사람도 바로 사용할 수 있게 됩니다.

# .claude-plugin/plugin.json
name: ppt-maker
version: 1.0.0
description: PPT 자동 생성 스킬

Slide 12 · 활용

활용 방법

  • 강의 자료 제작 — 강사 / 교육 콘텐츠 팀

  • 투자 피칭 자료 — 스타트업 IR 덱
