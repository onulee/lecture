1. Claude Code 소개 02 / 14

Claude Code란?

핵심 특징
AI 기반
코드를 이해하고 실행하면서 자동으로 결과를 만드는 개발 환경
중심 개념
Skill
특정 작업을 자동으로 수행하는 작은 AI 프로그램 단위
실행 방식
CLI / IDE
터미널, VS Code, JetBrains에서 즉시 실행 가능

➡ Skill은 역할 정의 → 입력 처리 → 출력 생성의 3단계 구조로 동작합니다.

➡ 한번 만든 Skill은 반복 호출 가능 — 자동화의 핵심 단위입니다.

5. Skill Creator 작성 06 / 14

Skill Creator 작성법

핵심은 프롬프트 설계입니다

# 역할 정의

# 입력 처리
사용자가 주제를 주면

좋은 역할 정의

  • ○ 명확한 전문가 역할 부여

  • ○ 출력 범위 제한

피해야 할 패턴

  • ○ 역할이 모호한 지시
  • ○ 출력 형식 미정의
  • ○ 지나치게 긴 프롬프트

$ claude run ppt-skill

➡ 결과를 계속 수정하면서 품질을 높이는 반복이 핵심입니다.

10. 배포 핵심 포인트 11 / 14
☑

배포 시 핵심 3가지

1

명확한 설명

Skill이 하는 일을 한 문장으로 설명할 수 있어야 합니다

✓ "주제를 입력하면 PPT 구조를 자동 생성"
2

좋은 예시 입력

사용자가 바로 따라할 수 있는 구체적인 예시 3개 이상

✓ "스타트업 투자 PPT"
✓ "SaaS 제품 소개서"
3

결과 품질

출력 샘플을 README에 함께 공개하면 신뢰도 상승

✓ 스크린샷 또는 데모 링크 포함

➡ 이 3가지가 갖춰지면 사용자 채택률이 급격히 높아집니다.
